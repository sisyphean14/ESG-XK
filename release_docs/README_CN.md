# ESG-XK V1.1.0 — 本地 ESG 文档知识库管理系统

ESG-XK 是一款在 Windows 本机运行的 ESG 文档知识库：导入与管理 PDF / Word / Excel / PowerPoint / 文本 / 图片文档，
解析与 OCR（中文 / English / Bahasa Indonesia），全文检索、元数据检索、跨语言语义检索，以及带引用的本地 AI 问答。

## V1.1.0 新增
- **Office 内嵌图片 OCR**：识别 DOCX（内嵌 / 浮动 / VML / 表格内图片）、PPTX（幻灯片图片、组合形状中的图片）、
  XLSX（工作表图片，锚点单元格）中的截图、扫描图、流程图、通知截图等；三语 OCR；自动过滤图标 / 装饰图 / 极小图；
  同一图片按 SHA-256 只 OCR 一次，每个出现位置独立定位、可被分别引用；旋转截图自动旋转重试。
- 图片中的文字进入全文检索、向量检索与 AI 问答，结果与引用明确标注“命中来源：内嵌图片OCR”及位置
  （例如《制度.docx》章节「2 专项检查」· 第4段附近 · 内嵌图片 4；《培训.pptx》第8张幻灯片 · 内嵌图片 2）。
- **处理可靠性**：解析在独立子进程执行；所有长耗时任务采用“无进展超时”；OCR / Embedding 单元失败自动重试 1 次后跳过；
  独立 Watchdog 监控 Worker 心跳与进展，卡死自动终止、回收并继续队列；单个坏文件永远不会阻塞整个处理队列。
  Run 新增“已完成（有错误）”状态、部分成功、超时等状态，并生成失败清单。
- **模型下载中心**（左侧“模型下载”）：按本机硬件推荐并手动点击下载 AI 模型与完整 PP-OCR 运行时
  （llama.cpp CPU / CUDA、Qwen3 Embedding / Reranker / LLM、PP-OCRv5 模型、Python 3.12 + PaddlePaddle + PaddleOCR）；
  **下载前选择安装位置**（默认程序文件夹内 `AI-Models`）；版本与 SHA-256 固定在内置清单中、逐文件校验；
  国内镜像优先、断点续传、可取消；安装完成后自动配置到 AI 资产中心。
- **扫描电脑**（设置 → AI资产中心 →【扫描电脑…】）：选择磁盘 / 文件夹后手动开始，查找电脑上已有的 GGUF 模型、
  llama-server、PP-OCR 运行时与模型目录、Ollama 模型库，选中即可连接（只引用原路径，绝不移动 / 复制 / 修改）。
- **数据保存在程序文件夹内（便携模式）**：首次运行可选择把数据与配置都保存在程序文件夹里（`ESG-XK-Data\`、`profile\`），
  不占用 C 盘、不会遗失，整个文件夹可直接复制到移动硬盘或另一台电脑；已有数据可在 设置 → 数据目录 中
  “迁移到程序文件夹内”（复制 + 逐文件 SHA-256 + 数据库完整性检查，通过后才切换，原目录保持不变）。

## 快速开始
1. 把 `ESG-XK-1.1.0-portable` 文件夹放到一个可写的位置（例如 `D:\ESG-XK\`，不要放在 `C:\Program Files`）。
2. 双击 `ESG-XK.exe`（无需安装、无需 IDE、无需 Python）。
3. 首次运行选择数据保存位置：推荐“保存在程序文件夹内（便携模式）”。
4. 需要 OCR / AI 功能：左侧“模型下载”→ 勾选推荐组件 → 选择安装位置 →【开始下载并安装】；
   电脑上已有模型：设置 → AI资产中心 →【扫描电脑…】。两者都可跳过，文档管理与全文检索不依赖 AI。
5. 左侧“导入中心”→ 导入文件或文件夹（源文件只读，不会被修改）。
6. “处理中心”→ 选择文档与 Pipeline →【开始处理】。
7. “全文搜索 / 知识检索 / AI问答”使用知识库。

## 核心原则
- **源文件只读**：不修改、不覆盖、不删除、不重命名任何源文件；“托管副本”仅在您选择时复制。
- **无定时处理**：没有计划任务、夜间处理或后台服务；所有处理都由您点击开始，程序退出后不会继续处理。
- **可停可续**：暂停 / 继续 / 安全停止（保存 Checkpoint）/ 急停，均可从 Checkpoint 续跑。
- **可追溯**：检索结果与 AI 回答都带文档、版本、页码 / Sheet / Slide / 段落定位与原文片段；无依据时显示“知识库中未找到足够依据”。
- **本地优先**：不上传文件、无遥测、无账号；只有在“模型下载”页点击【开始下载】时才联网下载模型（只下载、不上传）。
  AI 资产（OCR、Embedding、Reranker、LLM）为可选增强，未配置时其余功能照常使用。

## 目录说明
| 文件 | 说明 |
|---|---|
| ESG-XK.exe | 主程序（同一 EXE 也作为处理 Worker 由程序自身按需启动） |
| _internal\ | 运行时组件（请勿修改） |
| config\profile.template.json | 本机 Profile 模板（说明字段含义） |
| portable.flag、profile\、ESG-XK-Data\、AI-Models\ | 首次运行选择便携模式 / 下载模型后才会出现：本机配置、数据目录、下载的模型（交付包中不含） |
| USER_GUIDE_CN.md / ADMIN_GUIDE_CN.md | 用户说明 / 管理员说明 |
| RELEASE_NOTES.md / VERSION.txt | 版本说明 |
| MANIFEST.json / SHA256SUMS.txt | 交付清单与校验值 |
| LICENSES\ | 第三方组件许可证 |

系统要求：Windows 10/11 x64；建议 16 GB 内存；AI 功能需要 llama.cpp 与 GGUF 模型、PP-OCR 运行时——
可在“模型下载”中一键下载（推荐组合约 5 GB），或用“扫描电脑”连接已有资产（见用户说明第 15–17 节）。
分享给家人 / 同事：直接复制**交付包**（不要复制自己已使用过的文件夹，其中含有自己的数据与配置）。
