ESG-XK 本地 ESG 文档知识库 V1.1.0 —— 快速上手
==================================================

一、第一次打开
1. 双击 ESG-XK.exe（或桌面上的“ESG-XK”快捷方式）。
   如果 Windows 提示“已保护你的电脑”，点击“更多信息”→“仍要运行”（本程序没有数字签名，属正常提示）。
2. 出现“数据保存在哪里？”时，保持默认的“保存在程序文件夹内（推荐）”，点“开始使用”。
   以后所有数据都保存在这个文件夹里，不占 C 盘，不会丢。

二、需要 OCR（识别扫描件 / 图片文字）和 AI 问答时
1. 点左侧“模型下载”。程序会按你电脑的配置自动勾选推荐的组件。
2. 安装位置保持默认（程序文件夹里的 AI-Models）即可，点“开始下载并安装”。
   推荐组合约 5 GB，需要联网，时间取决于网速；下载中可以继续使用其他功能，也可以随时取消，下次接着下。
3. 装好后程序会自动配置好，右上角“AI资产”显示 ✓ 就可以用了。
   不下载也没关系：导入文档、全文搜索等功能照常能用。

三、日常使用
1. “导入中心”：把文件或文件夹拖进来（原文件不会被修改）。
2. “处理中心”：选中文档，点“开始处理”（程序不会自己偷偷处理，一切都要你点击）。
3. “全文搜索 / 知识检索 / AI问答”：查资料、问问题，结果都会标出来自哪个文件、第几页。
4. 右上角红色“急停”：任何时候想立刻停止处理都可以点。

四、备份与换电脑
- “备份恢复”可以一键备份。
- 整个程序文件夹（包括 ESG-XK-Data 和 AI-Models）可以直接复制到移动硬盘或另一台电脑继续使用。

五、卸载
- 本程序不写注册表、不装服务。不想用了，删除整个程序文件夹（以及桌面快捷方式）即可。
  注意：删除前如有需要，请先备份文件夹里的 ESG-XK-Data（你的数据都在里面）。

更详细的说明见同一文件夹中的 README_CN.md 和 USER_GUIDE_CN.md。
