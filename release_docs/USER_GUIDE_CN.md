# ESG-XK 用户说明

## 1. 首页
显示文档总数、有效文档、待处理 / 处理中 / 成功 / 失败、OCR 数量、Chunk、全文索引、向量索引、知识条目、数据库大小、
数据目录位置、AI 状态、OCR 状态、当前处理任务，以及最近导入、最近处理、最近错误。首页只读取统计，不会启动任何处理。

## 2. 导入中心
- **导入文件… / 导入文件夹… / 拖拽**：支持 PDF、DOCX、XLSX、PPTX、TXT、MD、CSV、PNG、JPG、JPEG、WEBP、BMP、TIFF。
- **管理方式**：“引用原始文件”（只记录位置，推荐）或“托管副本”（复制到数据目录的 managed_files）。
- **递归子文件夹**、**登记为来源目录**：登记后可在“来源目录”中执行 **增量扫描**（大小与修改时间未变的文件跳过）或 **完全重新同步**。
- 识别规则（以 SHA-256 为准，不以文件名判断）：
  - 同一路径内容变化 → **新版本**（旧版本保留在版本历史中）；
  - 不同文件内容完全相同 → **重复**；
  - 原路径消失、内容出现在新路径 → **重命名/移动**；
  - 来源目录中文件消失 → 文档标记为 **源文件缺失**（不删除任何数据）。
- 导入队列：等待 / 处理中 / 完成 / 失败 / 跳过 / 重复 / 暂停 / 取消；可 **暂停、继续、取消、重试失败**，双击查看详情。
- 导入只登记文件，不会自动解析。

## 3. 文档库
过滤（标题、审核状态、处理状态、类型、标签、文件状态），多选后可：添加/移除标签、设置审核状态、设置有效性与有效期、送去处理、
导出列表、移出知识库（可恢复，不删除源文件）。双击打开 **文档详情**：基本信息与元数据编辑、版本历史、解析与 OCR（含原始 OCR 文本、
引擎、语言、置信度）、Chunk、处理历史、相关错误；可手动 **重新解析 / 重新OCR / 重新Chunk / 重新索引 / 重新Embedding**。

## 4. 处理中心
1. 选择文档（待处理 / 失败 / 部分完成 / 全部 / 从文档库送来的文档）。
2. 选择 Pipeline：
   - **可检索语料（SEARCHABLE_CORPUS，默认）**：解析、OCR、切分、全文索引；Embedding 可用时生成基本向量索引。
   - **本地知识标准（LOCAL_KNOWLEDGE_STANDARD）**：增加语义索引、知识结构化与治理字段，支持 Reranking 与 RAG。
3. 【开始处理】。运行中可：
   - **暂停**：当前原子阶段完成后暂停，不再领取新任务；**继续** 恢复。
   - **安全停止**：完成当前最小原子阶段（解析、每页 OCR、每批向量等）→ 提交 → 写 Checkpoint → 释放资源 → Worker 退出。
   - **急停**（红色按钮，顶栏始终可见）：立即终止全部处理进程与 OCR / Embedding / LLM 子进程，未提交阶段不会写入数据库，
     完成后显示校验报告（进程、端口、租约、数据库完整性）。
   - **继续 Checkpoint**：从安全停止 / 急停 / 异常中断处续跑，已完成的工作不会重做。
   - **重试失败**：把失败文档重新排队。
4. 进度显示当前阶段、当前文档、成功 / 失败 / 跳过 / 剩余数量；“预计剩余”为粗略估算。
单个文档失败（如损坏文件）不会影响其他文档，失败原因以错误码显示（例如 `PARSE_CORRUPTED`）。

## 5. 全文搜索
关键词（空格分隔，全部 / 任一）、短语（双引号）、文档名、元数据/标签检索；过滤类型、语言、标签、来源、审核状态、有效性、导入日期、
历史版本。结果高亮关键词、显示上下文、文档版本与定位（页码 / Sheet 行 / Slide / 段落），点击查看来源或文档详情。
另有“元数据检索”页签，按业务领域、部门、类型、项目、区域、年份、备注、自定义字段等查找文档。

## 6. 知识检索
混合检索（关键词召回 + 向量召回 + Reranker 重排）、向量检索、全文检索。支持中文 / English / Bahasa Indonesia 之间跨语言检索。
Embedding 不可用时自动降级为全文检索并说明原因；可勾选“跨语言查询扩展”（使用本地 LLM 翻译查询）。

## 7. AI 问答
只依据检索到的资料回答，关键结论后带 [编号] 引用；点击编号或引用查看原文、版本与定位。
- 找不到足够依据时显示“知识库中未找到足够依据”；模型回答未引用资料时会被拒绝显示。
- 默认只使用“已批准 + 当前有效”的当前版本文档（管理员可放开草稿）。
- 本地 LLM 不可用时，仅展示检索到的依据片段。

## 8. 知识管理
审核治理（草稿 → 待审核 → 已批准 → 已失效，有效期）、标签管理（新建、重命名/合并、删除）、自定义字段、知识条目（按 ESG 主题浏览）。

## 9. 运行控制
处理任务历史、Checkpoint 记录、资源 Profile 与内存、重型 AI 槽位、Worker / Helper 进程、租约状态；可继续 / 重试 / 安全停止 / 急停、
释放交互式 AI 模型、执行数据库完整性检查。

## 10. 备份恢复
完整 / 数据库 / 配置 / 索引 / 知识元数据备份（可选包含托管文件；外部引用源文件不备份）。恢复前自动创建安全备份，
校验 Manifest、SHA-256、Schema，恢复后执行完整性检查，失败自动回滚。处理任务运行时不能备份或恢复。

## 11. 日志中心
按级别、分类（运行 / 错误 / 技术 / 审计 / 处理 / OCR / RAG / Migration / Backup / 急停 / 导入 / 检索）、模块、Run、日期过滤与搜索；
查看 Traceback、复制错误信息、导出 CSV。

## 12. 关闭程序
若有任务运行，会提示：**安全停止后退出**（默认）/ 强制急停并退出 / 取消退出。退出时核对 Worker、Helper、租约与端口均为 0。
